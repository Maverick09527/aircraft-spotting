# 大型客機辨識 LLM Wiki

這是可作為 GitHub 專案根目錄上傳的完整 Wiki 專案。

## 專案內容

- `AGENTS.md`：LLM Wiki 維護規則與 ingest/query/lint 流程。
- `raw/`：原始來源 PDF、來源清單與保存說明。
- `wiki/`：索引、來源摘要、六型機型頁、比較表、辨識指南、簡報腳本與流程紀錄。
- `aircraft-spotting-slides.html`：教學型 HTML 簡報。

建議先預覽 `wiki/index.md` 和 HTML 簡報，再將此資料夾作為 repository 根目錄上傳。`raw/` 中的官方 PDF 是來源材料；若 repository 設為公開，請先確認各 PDF 的再散布條件。A380 官方原始 PDF 未保存本地，Wiki 內保留官方連結與摘要。
